# Voice OS (Голос) / Neuro-OS

**Компьютер, который понимает, что вам нужно.**

Voice OS — операционная система, где вместо сотни программ — один диалог. Пользователь описывает задачу на естественном языке, система исполняет.

## Текущее состояние (Neuro-OS v1)

Рабочий прототип на сервере `korol4ik.org`. Всё работает.

### Стек
| Компонент | Что делает |
|-----------|-----------|
| **nginx** | порт 80/443, HTTPS, auth_basic, прокси API |
| **OpenClaw Gateway** | LLM-ядро (DeepSeek), общая сессия TUI + Web |
| **ChromaDB** | семантическая память (all-MiniLM-L6-v2) |
| **index.html** | единственная веб-страница — чёрный терминал |
| **showApp()** | загрузка приложений на лету |
| **/api/ls/** | быстрый эндпоинт списка файлов (без модели) |

### Память
- **ChromaDB** — векторное хранилище событий, ответов, созданных интерфейсов
- **commands_index.md** — индекс команд (52 шт, с категориями)
- **requests.log** — хронология запросов

### Приложения (apps)
Приложения создаются на лету под задачу. Структура:
```
apps/gallery.html      — шаблон
apps/css/gallery.css   — стили
apps/js/gallery.js     — логика
```

- **gallery** — просмотр файлов, изображений, аудио/видео (в т.ч. по URL из интернета)
- Поддерживаются hash-триггеры: `/#gallery:/path`

### Ключевое слово ЗАПОМНИ
Если пользователь пишет «запомни» — информация сохраняется в наиболее подходящий файл `~/.neuro-os/*`.

## Философия

Современные ОС заставляют думать как компьютер: искать программы, запоминать пути, разбираться в меню. Voice OS переворачивает парадигму:

- **Интерфейс — это диалог.** Нет иконок, нет меню. Есть поле, куда вы пишете, что нужно сделать.
- **Программы создаются на лету.** Система понимает задачу и создаёт интерфейс.
- **Интерфейс исчезает после выполнения.** Никакого хаоса из окон.
- **Работает локально.** Векторная БД и (в перспективе) LLM — на вашем устройстве.
