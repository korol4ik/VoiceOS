# Neuro-OS — индекс команд

## Система
- systemctl — управление systemd
- journalctl — логи systemd
- ps, top, htop — процессы
- kill, killall — завершение процессов
- df, du — диски
- free — память
- uname, hostname — система
- uptime — аптайм
- who, w, last — кто в системе

## Сеть
- curl, wget — HTTP-запросы
- ss, netstat — сокеты
- ping, traceroute — диагностика
- iptables — фаервол
- ip, ifconfig — интерфейсы
- nginx -t, nginx -s reload — nginx

## Файлы
- ls, find, locate — поиск
- cat, less, head, tail — чтение
- cp, mv, rm, mkdir — операции
- chmod, chown — права
- ln — ссылки
- tar, gzip, zip — архивы
- rsync, scp — копирование

## Пакеты
- apt-get install/remove — установка
- dpkg -l, dpkg -i — deb-пакеты
- pip install — Python-пакеты

## Python/JS
- python3 — запуск скриптов
- pip3 — пакеты Python
- node — JS-среда

## Текст
- grep, sed, awk — обработка
- sort, uniq, wc — анализ
- diff — сравнение
- echo, printf — вывод

## Медиа
- ffmpeg — видео/аудио
- convert (imagemagick) — изображения
- file — тип файла
