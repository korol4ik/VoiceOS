# Neuro-OS

**نظام تشغيل حيث الواجهة هي الحوار.**

يقول المستخدم ما يحتاجه — والوكيل ينفذ. النوافذ، الأزرار، الملفات — كل شيء يُنشأ عند الطلب ويختفي عندما لا يعود مطلوباً.

## بداية سريعة

1. قم بتثبيت [OpenClaw](https://openclaw.ai) أو أي وكيل ذكاء اصطناعي آخر.
2. استنسخ المستودع: `git clone https://github.com/korol4ik/VoiceOS`
3. وجه وكيلك إلى `VoiceOS/bootstrap.md`.
4. اتبع حوار الإعداد مع الوكيل — سطح المكتب جاهز.

يمكنك أيضاً توجيه الوكيل مباشرة إلى هذا المستودع — سيقرأ `bootstrap.md` ويبدأ الحوار.

## الهيكل

```
VoiceOS/

    │   ├── wm.js               ← مدير النوافذ
    │   ├── channel.js          ← قناة الأوامر (WS)

```

## المبادئ

- **HTML+CSS+JS خالص** — لا أطر عمل، لا A2UI.
- **حياد الوكيل** — bootstrap مكتوب بلغة طبيعية، يعمل مع أي وكيل ذكاء اصطناعي.
- **الخصوصية** — كل شيء يعمل محلياً، البيانات لا تغادر الخادم أبداً.
- **البساطة** — نتيجة فورية، بدون خطوات إضافية.

## التبعيات

- وكيل ذكاء اصطناعي (OpenClaw، Hermes أو أي آخر)
- خادم ويب (nginx، OpenClaw مدمج، Caddy — اختيار المستخدم)
- ChromaDB (اختياري، للذاكرة المتجهة)
