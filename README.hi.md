# Neuro-OS

**एक ऑपरेटिंग सिस्टम जहाँ इंटरफ़ेस बातचीत है।**

उपयोगकर्ता बताता है कि क्या चाहिए — एजेंट निष्पादित करता है। विंडो, बटन, फ़ाइलें — सब कुछ माँग पर बनता है और ज़रूरत न होने पर गायब हो जाता है।

## त्वरित आरंभ

1. [OpenClaw](https://openclaw.ai) या कोई अन्य AI एजेंट स्थापित करें।
2. रिपॉजिटरी क्लोन करें: `git clone https://github.com/korol4ik/VoiceOS`
3. अपने एजेंट को `VoiceOS/bootstrap.md` पर इंगित करें।
4. एजेंट के साथ सेटअप संवाद करें — आपका डेस्कटॉप तैयार है।

वैकल्पिक रूप से, एजेंट को सीधे इस रिपॉजिटरी पर इंगित करें — यह `bootstrap.md` पढ़ेगा और संवाद शुरू करेगा।

## संरचना

```
VoiceOS/
├── bootstrap.md                ← पहली बार चलाने के निर्देश (एजेंट पढ़ता है)
├── README.md
└── neuro-os/
    ├── core/                   ← एजेंट का व्यक्तित्व (कार्यक्षेत्र में कॉपी किया जाता है)
    │   ├── AGENTS.md
    │   ├── IDENTITY.md
    │   └── SOUL.md
    ├── index.html              ← डेस्कटॉप (प्रवेश बिंदु)
    ├── css/index.css           ← शैलियाँ
    ├── js/
    │   ├── config.js           ← स्थिरांक
    │   ├── drag.js             ← खींचना और आकार बदलना
    │   ├── wm.js               ← विंडो प्रबंधक
    │   ├── channel.js          ← कमांड चैनल (WS)
    │   ├── ui.js               ← चैट + REST API
    │   ├── ws.js               ← WebSocket
    │   └── app.js              ← आरंभीकरण
    ├── apps/                   ← उपयोगकर्ता के वेब एप्लिकेशन
    │   ├── css/
    │   └── js/
    └── user/                   ← उपयोगकर्ता का होम फ़ोल्डर
        ├── documents/
        ├── image/
        ├── video/
        └── audio/
```

## सिद्धांत

- **शुद्ध HTML+CSS+JS** — कोई फ्रेमवर्क नहीं, कोई A2UI नहीं।
- **एजेंट-तटस्थ** — bootstrap प्राकृतिक भाषा में लिखा गया है, किसी भी AI एजेंट के साथ काम करता है।
- **गोपनीयता** — सब कुछ स्थानीय रूप से चलता है, डेटा कभी सर्वर नहीं छोड़ता।
- **न्यूनतमवाद** — तुरंत परिणाम, कोई अतिरिक्त कदम नहीं।

## निर्भरताएँ

- AI एजेंट (OpenClaw, Hermes या कोई अन्य)
- वेब सर्वर (nginx, OpenClaw एम्बेडेड, Caddy — उपयोगकर्ता की पसंद)
- ChromaDB (वैकल्पिक, वेक्टर मेमोरी के लिए)
