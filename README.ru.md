# Neuro-OS

**Операционная система, где интерфейс — это диалог.**

Пользователь говорит, что нужно — агент исполняет. Окна, кнопки, файлы — всё создаётся по запросу и исчезает, когда не нужно.

## Быстрый старт

1. Установи [OpenClaw](https://openclaw.ai) или другого ИИ-агента.
2. Склонируй репозиторий: `git clone https://github.com/korol4ik/VoiceOS`
3. Укажи агенту путь к `VoiceOS/bootstrap.md`.
4. Пройди диалог настройки с агентом — и десктоп готов.

Либо укажи агенту на этот репозиторий напрямую — он сам прочитает `bootstrap.md` и начнёт диалог.

## Структура

```
VoiceOS/
├── bootstrap.md                ← инструкция первого запуска (агент читает)
├── README.md
└── neuro-os/
    ├── core/                   ← личность агента (копируется в workspace)
    │   ├── AGENTS.md
    │   ├── IDENTITY.md
    │   └── SOUL.md
    ├── index.html              ← десктоп (entry point)
    ├── css/index.css           ← стили
    ├── js/
    │   ├── config.js           ← константы
    │   ├── drag.js             ← drag & resize окон
    │   ├── wm.js               ← менеджер окон
    │   ├── channel.js          ← канал команд (WS)
    │   ├── ui.js               ← чат + REST API
    │   ├── ws.js               ← WebSocket
    │   └── app.js              ← инициализация
    ├── apps/                   ← веб-приложения пользователя
    │   ├── css/
    │   └── js/
    └── user/                   ← домашняя папка пользователя
        ├── documents/
        ├── image/
        ├── video/
        └── audio/
```

## Принципы

- **Чистый HTML+CSS+JS** — никаких фреймворков, никакого A2UI.
- **Агент-нейтральность** — bootstrap написан на человеческом языке, подходит для любого ИИ-агента.
- **Приватность** — всё локально, данные не покидают сервер.
- **Минимализм** — результат сразу, без лишних шагов.

## Зависимости

- ИИ-агент (OpenClaw, Hermes или любой другой)
- Веб-сервер (nginx, OpenClaw embedded, Caddy — на выбор пользователя)
- ChromaDB (опционально, для векторной памяти)
